# つなげて！ 名乗って！ 三国志　VAR

カードゲーム「つなげて！ 名乗って！ 三国志」で、入力した人物名の読みが有効かどうかを判定するためのスマホ向け静的Webアプリです。

## ファイル構成

- `index.html`：画面の土台です。
- `style.css`：文字サイズ、余白、ボタンなどの見た目を決めています。
- `app.js`：Excelファイルを読み込み、入力された読みを判定します。
- `data/names.xlsx`：判定に使う人物名データです。
- `start_local_server.bat`：PC上で確認するためのローカルサーバーを起動します。

## 判定データの更新方法

判定内容を変えたいときは、`data\names.xlsx` の「判定アプリ用」シートを更新してください。

「判定アプリ用」シートでは、1行目を見出しとして使います。

- A列：`よみ`
- B列：`表示人物名`

2行目以降が判定対象になります。Webアプリのファイルを直さなくても、将来は `data\names.xlsx` を差し替えるだけで判定内容を更新できます。

## PC上での起動方法

`index.html` を直接ダブルクリックして開くのではなく、ローカルサーバーで確認してください。

1. `start_local_server.bat` をダブルクリックします。
2. 黒い画面が開き、ローカルサーバーが起動します。
3. ブラウザで `http://localhost:8000/` を開きます。
4. 終了するときは、黒い画面を閉じるか、黒い画面で `Ctrl + C` を押します。

Python がPCに入っていない場合は、Python をインストールしてからもう一度試してください。

## 動作確認例

- `こうこう` と入力して判定すると、成功し、`黄皓／黄昂／黄祟／高弘／高光` のように表示されます。
- `そうそう` と入力して判定すると、成功し、`曹操／曹爽／曹琮／臧倉` のように表示されます。
- `こうめい` と入力して判定すると、失敗になります。

入力の前後に空白があっても判定できます。入力途中の全角スペース・半角スペースは削除されます。カタカナで入力した場合も、ひらがなに変換して判定します。
